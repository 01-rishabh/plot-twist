# Plot Twist: viewing registrations

Every form entry from the website lands in a Google Sheet as a new row. No extra app or login is needed beyond your Google account.

## Open the entries

1. Open the sheet link you were given (bookmark it), or find it in Google Drive.
2. Go to the **Responses** tab at the bottom.
3. Each row is one person. Column A is the date and time they signed up. The newest entry is at the bottom.

On a phone, install the **Google Sheets** app and open the same sheet.

## Everyday tasks

| To do this | Do this |
|---|---|
| Search for a name, email or phone | Press `Ctrl + F` (`Cmd + F` on Mac) |
| Sort or filter (for example, only one city) | Select row 1, then **Data > Create a filter**, and use the small icons in the header cells |
| Download as Excel | **File > Download > Microsoft Excel (.xlsx)** |
| Download as CSV | **File > Download > Comma-separated values (.csv)** |
| Give a teammate access | **Share** button (top right), add their email, choose Viewer or Editor |
| Track follow-ups | Add your own column with a header, for example `Called?` or `Notes` |
| Get an email for every new entry | Ask the developer to turn on `NOTIFY_EMAIL` in the script |

## Please do not

- Rename the **Responses** tab.
- Rename or delete the headers in row 1. New entries are matched to columns by these names.

Deleting or editing an individual entry row is fine. Google Sheets keeps a history: **File > Version history** restores earlier versions if something goes wrong.
